Prompt quality

A good prompt is small, specific, and reviewable.

  1. Explain the visible change you want.
  2. Keep the request inside the static lab scope.
  3. Say what should not change.
  4. Do not ask for login, payment, external APIs, trackers, or broad redesigns.

Execution boundary

The lab remains static and local.

The accepted implementation target is limited to lab/index.html, lab/style.css, and lab/app.js. This page works without network access, does not call external APIs, does not use cookies, and does not collect analytics.
