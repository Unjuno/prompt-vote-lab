Prompt Vote Lab

People vote on prompts. An AI coding agent implements the winning prompt. We review the PR and record the gap between expectation and result.

Experiment loop

  1. 1Propose

    Submit a prompt as a GitHub issue.

  2. 2Vote

    Use reactions to express collective expectation.

  3. 3Run

    The agent edits only this static lab UI.

  4. 4Review

    The maintainer merges, rejects, or revises.

  5. 5Analyze

    We classify the expectation gap.
