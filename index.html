What this is

A game about prompt judgment.

This is an experiment, but it is also a game. The skill is not merely writing a flashy prompt. The skill is writing a prompt that other players trust, the agent can act on, and the lab can absorb.

Votes are not proof of quality. A crowd favorite can produce a weak agent PR. If that happens repeatedly, players should learn not to trust that prompt style, author, or promise next time.

What counts

Winning the vote is not the same as winning the round.

The real score is whether the prompt survives implementation without wasting the lab.

Board limits

The small box makes the game legible.

Only the static lab can change. No external scripts, network calls, cookies, trackers, login, payment behavior, or automatic merges.

Allowed

Static HTML, CSS, vanilla JavaScript, helper functions, local state, and local JSON import/export.

Blocked

External runtime dependencies, hidden calls, identity systems, payment flows, and unsafe dynamic code.

Inherited

Only merged lab PRs become the base state for future weekly prompts.
