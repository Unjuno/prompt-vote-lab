Execution threshold

20

virtual votes
No change this week starts with 20 virtual votes. A real prompt must beat it.

  • API budget is spent only when a prompt is eligible.
  • Each candidate gets one single-shot implementation attempt.
  • Merge is manual after review.

The loop

One path, four steps

Propose

Create a GitHub Issue with the prompt and expected visible result.

Vote

Use GitHub reactions. The prompt must outrank the no-change baseline.

Run

The selected prompt is attempted inside lab/ only.

Review

The generated PR is checked, reviewed, merged, rejected, or recorded as failed.

Safety boundary

Small enough to inspect

3 editable files

Implementation runs may edit only lab/index.html, lab/style.css, and lab/app.js.

No external runtime

No CDNs, external scripts, network fetches, cookies, iframes, eval, or hidden trackers.

No automatic merge

The AI can propose a PR. It cannot decide final adoption.

Support

Support funds comparison, not control

Support can help fund extra comparison runs and reporting. It does not override votes, bypass the 20 virtual votes baseline, or buy merge rights.
