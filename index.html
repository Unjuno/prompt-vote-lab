What this is

A weekly public prompt market, not a roadmap.

Prompt Vote Lab is an observable experiment. People vote for what the agent should try next, then the result is inspected as a gap between expectation and actual output.

The lab is cumulative. Each accepted change becomes the starting state for later weeks, so the experiment can become cleaner, stranger, more useful, or harder to maintain over time.

Weekly loop

Four steps. No hidden magic.

Propose

Write a concrete prompt and expected visible result as a GitHub Issue.

Vote

Use reactions. The prompt must beat the 20-vote no-change baseline.

Run

The fixed implementation agent gets one bounded attempt and opens an agent PR.

Review

Merge is manual. Only merged PRs become the inherited lab state.

Constraints

The small box is the experiment.

Keeping the agent inside a tiny static lab makes failures visible and comparisons easier.

Static HTML, CSS, vanilla JavaScript, helper functions, local state, and local JSON import/export.

Blocked

External scripts, CDNs, network calls, WebSockets, cookies, iframes, hidden trackers, login, and payment behavior.
