# support-unlocked-runs-v1.1

## Purpose

Support-unlocked runs allow additional ranked candidates to be executed after the normal weekly run.

Support is a contribution to the experiment. It does not guarantee success, adoption, or merge.

## Weekly candidates

Each weekly vote may produce ranked candidates:

- rank 1: normal weekly run
- rank 2: optional support-unlocked comparison run
- rank 3: optional support-unlocked comparison run

## Recommended one-time support tiers

- 5 USD: Support Rank 2 Comparison Run
- 10 USD: Support Rank 3 Comparison Run
- 20 USD: Support the Experiment

## Initial thresholds

- rank 2 comparison run: 5 USD weekly support
- rank 3 comparison run: 10 USD total weekly support

These thresholds are experimental and may change.

## Support the Experiment tier

The 20 USD tier is general project support.

It may help cover:

- API costs
- weekly reports
- failed-run analysis
- rule maintenance
- workflow maintenance

It does not create an extra mainline path.

## Scope

Support applies to the current weekly vote only.

Old weekly candidates are not automatically reopened.

## Safety policy

Support opens an additional experiment run only.

All support-unlocked runs must still follow:

- `static-ui-v1.0`
- `merge-policy-v1.0`
- maintainer review
- PR-only workflow

## Naming

Use ranked names:

- `week-XXX-rank-1`
- `week-XXX-rank-2`
- `week-XXX-rank-3`
