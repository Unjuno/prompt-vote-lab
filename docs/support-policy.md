# Support policy

Support helps Prompt Vote Lab run additional experiments and publish reports.

Support is not a purchase of success, adoption, merge, or specification control.

## Recommended one-time tiers

- 5 USD: Support Rank 2 Comparison Run
- 10 USD: Support Rank 3 Comparison Run
- 20 USD: Support the Experiment

## Weekly thresholds

- rank 2 comparison run: 5 USD weekly support
- rank 3 comparison run: 10 USD total weekly support

The 10 USD threshold is total weekly support, not 5 USD plus 10 USD.

## Scope

Support applies to the current weekly vote only.

Old weekly candidates are not automatically reopened.

## General support

The 20 USD tier may help cover:

- API costs
- weekly reports
- failed-run analysis
- rule maintenance
- workflow maintenance

## Safety

All support-unlocked runs still follow:

- static UI rules
- fixed implementation model policy
- safety checks
- PR-only implementation flow
- merge policy
